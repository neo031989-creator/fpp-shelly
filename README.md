# fpp-shelly

Falcon Player (FPP) Plugin zur Steuerung von Shelly Smart Home Geräten (Ein/Aus/Toggle).

## Features
- **FPP 10.0+ Kompatibel** (C++20, Modernes Command API)
- **GUI Integration:** Verwalte und teste Shelly-Geräte direkt im FPP Webinterface unter *Input/Output Settings -> Shelly Control*.
- **Playlist & Command Presets:** Führt Befehle nativ über den FPP Command `Shelly Control` aus.

## Installation
1. Lade diese ZIP-Datei herunter oder clone das Repo nach `/home/fpp/media/plugins/fpp-shelly`.
2. Starte den FPP-Daemon neu oder compiliere manuell mit `make -C src`.
